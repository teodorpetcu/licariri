# licariri

Site-ul web al Revistei Licăriri.

## Instalare

[Preferabil pe un sistem Linux/MacOS]

Necesită:

- npm, pentru instalare
- NodeJS, pentru rulare
- SQLite 3, pentru rulare

Pentru instalare, execută comenzile:

```
git clone https://github.com/xylous/licariri licariri
cd licariri
npm install
```

## Folosire

Pentru a demara aplicația, în rădăcina directoriului proiectului, execută
comanda:

```
node .
```
