# Backend NodeJS

- data: (cca. 2024)
- stadiu: implementat

---

## Context

Trebuie ales un limbaj de programare pentru backend.

## Opțiuni

1. JavaScript (prin NodeJS)
2. Python
3. JavaScript/TypeScript (prin Deno)

## Decizie

Am optat pentru NodeJS pentru că tot JavaScript rulează și frontend-ul; este mai
simplu să folosești același limbaj și în backend decât să trebuiască să
stăpânești două limbaje diferite. În plus, motorul NodeJS e mai rapid decât
interpretatoarele Python.

Nu am ales Deno pentru că nu aveam experiență cu TypeScript.

## Consecințe

Toate framework-urile și librăriile alese ulterior aparțin ecosistemului NodeJS
și `npm` (ceea ce nu-i un dezavantaj; din contră, există foarte multe opțiuni).
